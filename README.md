# ИИ-агент поверх локальной нейросети

Локальная LLM (Ollama + Qwen) управляет компьютером с Ubuntu: сама пишет
shell-команды, читает вывод, видит интерфейс, нажимает кнопки и помнит уроки.
**Ноль зависимостей** — только Python 3 и работающий Ollama. Работает даже на
слабом железе: от 3–4 ГБ RAM в виртуальной машине.

```
[шаг 1] АГЕНТ -> ПК: {"open": "firefox"}
          ПК -> АГЕНТ: ФАКТ: «firefox» запущен и окно АКТИВНО
[шаг 2] АГЕНТ -> ПК: {"scan": ""}
          ПК -> АГЕНТ: КНОПКА [ 71, 259] «Background»  ...
[ГОТОВО за 4 шаг(ов)] Firefox открыт, нужная кнопка найдена и нажата
```

## Быстрый старт (5 минут)

```bash
# 1. Мозг
ollama pull qwen2.5:3b        # или свой GGUF через Modelfile
ollama serve                  # в отдельном терминале, держать открытым

# 2. Агент
AGENT_MODEL=qwen2.5:3b python3 agent_v4_2.py
```

## Безопасность

Агент реально выполняет команды. DENY-лист режет деструктивное, но это не
песочница: запускайте в виртуальной машине со снапшотами, а для первых
запусков — `CONFIRM=1` (ручное одобрение каждого действия).
