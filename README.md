# ИИ-агент поверх локальной нейросети — Часть 1: версии 1.0 → 3.1
Локальная нейросеть (Ollama + Qwen) управляет компьютером с Ubuntu: сама
придумывает shell-команду → ПК выполняет → вывод уходит обратно нейросети →
следующее решение. Ноль зависимостей: только Python 3 и работающий Ollama
(взаимодействие — через REST API чистым urllib).

Философия проекта: маленькой локальной модели не хватает ума — добавь ей
органов чувств, памяти и правил, а не параметров.

[шаг 1] АГЕНТ -> ПК: {"command": "uname -r"}
          ПК -> АГЕНТ: 6.8.0-41-generic
[шаг 2] АГЕНТ -> ПК: {"command": "nproc"}
          ПК -> АГЕНТ: 2
[ГОТОВО за 3 шаг(ов)] Ядро 6.8.0-41-generic, процессорных ядер: 2
Как это работает
Модель общается строгим JSON-протоколом, одно действие за шаг:

{"command": "одна shell-команда"}   — выполнить и вернуть вывод
{"done": "итог по-русски"}          — задача завершена (по фактам!)
Агент-обёртка выполняет команду, обрезает вывод под маленький контекст
локальной модели, отдаёт обратно. Слабые модели (1.5B–3B) склонны
галлюцинировать успех — поэтому протокол требует доказывать всё фактами
(pgrep, ls, cat), а не словами.

Подготовка (общая для всех версий)
# 1. Установите Ollama
Bash

curl -fsSL https://ollama.com/install.sh | sh
Если скрипт недоступен — вручную со страницы релизов:
https://github.com/ollama/ollama/releases (файл ollama-linux-amd64),
распаковать в /usr/local/bin и /usr/local/lib.

# 2. Модель («мозг»)
Простой путь:

Bash

ollama pull qwen2.5:3b
Или свой GGUF-файл (пример с Qwen2.5-3B-Instruct):

Bash

mkdir -p ~/brain && cd ~/brain
Скачайте qwen2.5-3b-instruct-q4_k_m.gguf сюда
echo "FROM ./qwen2.5-3b-instruct-q4_k_m.gguf" > Modelfile
ollama create mybrain -f Modelfile
ollama list          # проверка: модель появилась
3. Сервер должен работать
В отдельном терминале (держите его открытым):

Bash

ollama serve
Сколько нужно памяти?

qwen2.5:1.5b	~1.5 ГБ	3 ГБ
qwen2.5:3b	~2.6 ГБ	4 ГБ

python3 agent_ollama.py "покажи версию ядра и количество ядер"
python3 agent_ollama.py "создай файл /tmp/note.txt с текущей датой и покажи его"
AGENT_MODEL=mybrain python3 agent_ollama.py "..."   # своя модель
Встроенная политика безопасности DENY: rm -rf, sudo, dd, shutdown
и подобные команды не выполняются, даже если их придумала нейросеть.

# v2.0 — память и автономия
Bash

python3 agent_v2.py
Внутри:

text

Вы > создай файл hello.txt на рабочем столе   — обычная задача
Вы > /free 5                                   — автономия на 5 целей (сама придумывает!)
Вы > /memo                                     — дневник
Вы > /exit                                     — выход (память сохранится)
После каждой задачи модель пишет себе урок в ~/agent_notes.txt
(последние ~15 подмешиваются в системный промпт — память переживает
перезапуск). Полный журнал — в ~/agent_diary.md.

CONFIRM=1 python3 agent_v2.py — спрашивать разрешение [y/n] на каждую команду.

/free 10 теперь работает непрерывно: этап → секунда паузы → следующий

# v3.1 «КНОПКОДАВ» — первые GUI-руки
Дополнительно поставьте:

Bash

sudo apt install -y xdotool            # обязательно для кликов/клавиш
sudo apt install -y python3-dogtail    # опционально: семантические клики
Важно: GUI-клики работают только в сеансе X11:

Bash

echo $XDG_SESSION_TYPE   # нужен вывод: x11
Если wayland — на экране входа кликните пользователя, затем шестерёнку ⚙
в правом нижнем углу и выберите «Ubuntu on Xorg» (запоминается навсегда).

Агент знает: панели Настроек (gnome-control-center background|appearance|wifi|...),
обои через gsettings, скриншоты gnome-screenshot, паттерн «запустил →
pgrep → факт → done».
